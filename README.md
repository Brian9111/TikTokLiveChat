# TikTok Live Chat

A modern, glass-inspired TikTok LIVE chat overlay for Windows.

## Features

* Real-time TikTok LIVE comments
* Gift events and live statistics
* Customizable text size and transparency
* Always-on-top and Stream Mode
* Copy and export chat logs
* Modern dark glass-inspired interface
